# ColaMD Changelog

欢迎来到 ColaMD 的**可玩 changelog**。左侧面板列出的就是本目录的文件——点击切换，每个文件演示一组功能。这是演示副本，玩坏了随时可以从仓库恢复。

---

## v1.0.0 · 优雅 Plus 主题（全新起点）

- **优雅 Plus 主题**：主菜上场。暖米色纸张感背景 `#f0edea`、赤陶红强调色 `#c44b2b`、衬线正文（LXGW WenKai 优先）+ JetBrains Mono 等宽代码；字间距 `0.04em` + 行高 `1.9`，中英文都有呼吸感
- **自动深色模式**：跟随系统外观自动切换为深墨配色（`#1c1a18` 背景、提亮的 `#e0653f` 强调色），暗色不是简单反色
- **代码块复制按钮**：悬停代码块，右上角出现「复制」按钮，一键复制（不带上语言标记）
- **主题 · 优雅 Plus**：菜单「主题」新增独立入口（⌘ 无需切换的第五个内置主题）

## v1.7.2 · 演示页与面板打磨

- **可玩演示页**：本页就是。之后每个大版本更新都会追加到这份 changelog
- **文件面板开关按钮**：标题栏右侧的竖线图标，点击切换面板（或 **⌘⇧B**）
- **待办点击修复 + 居中对勾**：checkbox 现在真的能点了（修了 v1.6.1 起的隐藏 bug），对勾换成 SVG 精确居中

## v1.7.1 · 同目录文件列表

- 打开文件时，左侧面板列出同目录的 Markdown 文件，点击**就地切换**
- Agent 新建/删除文件，面板**实时刷新**（试试下面的模拟 Agent）
- 有未保存的修改时，切换文件会先确认

## v1.7.0 · 搜索 + LaTeX

- **⌘F** 搜索当前文档，匹配项高亮
- **⌘⇧E** 插入 LaTeX 公式（KaTeX 渲染），点击公式可编辑

## 更早

v1.6.x — 可勾选的待办列表、`==高亮==` 语法、Markdown 语法速查、实时同步加固。详见 [GitHub Releases](https://github.com/marswaveai/colamd/releases)。

## 模拟 Agent

打开终端，对当前目录做点改动，窗口会实时响应：

```bash
echo '- [ ] 这是 Agent 刚写入的任务' >> tasks.md
echo '# 全新文件' > new.md
```

第二行会**实时**出现在左侧面板里——文件面板和内容一起动。

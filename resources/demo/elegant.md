# 优雅 Plus 主题演示

首字下沉：这一段的第一个字会被放大成装饰性大写——纸张感、呼吸感，让每一个字符都拥有自己的空间。暖米色背景 + 赤陶红强调色，中英文混排都不拥挤。

## 排版细节

正文使用衬线字体（**LXGW 霞鹜文楷** 优先），字间距 `0.04em`、行高 `1.9`。**加粗**、[链接](https://colamd.com)、`行内代码`、引用条都统一用赤陶红。

### 行内元素

- **加粗**：赤陶红强调
- `行内代码`：浅纸色芯片，红色字体
- ==高亮==：赤陶红淡色背景，不再是默认黄
- ~~删除线~~：红删除线，半透明
- <kbd>⌘</kbd><kbd>⇧</kbd><kbd>S</kbd>：拟物键盘键
- 脚注[^1]

[^1]: 脚注文字会用更小的字号和次级颜色呈现。

## 代码块

悬停代码块，右上角会出现「复制」按钮 🙂。

```js
const quote = '代码块使用深色面板 + One Dark 配色'
function breathe() {
  return '让代码也有呼吸的空间'
}
```

## 引用块

> 优雅不是装饰，而是让每一个字符都拥有呼吸的空间。
>
> —— 引用条用的是赤陶红，hover 时会稍微加宽。

## 表格

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--cola-bg` | `#f0edea` | 页面背景（暖米色） |
| `--cola-accent` | `#c44b2b` | 强调色（赤陶红） |
| `--cola-border` | `#d8d3ce` | 边框 |
